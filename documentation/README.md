# Projektdokumentation Diplomarbeit

Die Dokumentation wird mit [Typst](https://typst.app/) erstellt.

## Build

```bash
typst compile main.typ
```

Live-Vorschau während des Schreibens:

```bash
typst watch main.typ
```

## Struktur

| Datei / Ordner | Inhalt |
| --- | --- |
| `main.typ` | Einstiegspunkt, Layout, Verzeichnisse, Eigenständigkeitserklärung |
| `titelblatt.typ` | Deckblatt |
| `works.yml` | Quellen für das Literaturverzeichnis (Hayagriva-Format) |
| `chapters/` | Kapitel der Arbeit |
| `diagrams/` | PlantUML-Quellen (`.txt`) und exportierte Diagramme (`.png`) |
| `screenshots/` | Screenshots der Anwendung |

## Vorgaben

Die Gliederung folgt den «Richtlinien Diplomarbeit Herbst 2026» der TEKO.

Dateiname der Abgabe: `DA_Jahr_Name_Vorname_Klasse.pdf`
